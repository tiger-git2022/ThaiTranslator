# 泰语字幕翻译

[![最新版本](https://img.shields.io/github/v/release/tiger-git2022/ThaiTranslator?label=%E6%9C%80%E6%96%B0%E7%89%88%E6%9C%AC)](https://github.com/tiger-git2022/ThaiTranslator/releases/latest)
[![打包发布](https://github.com/tiger-git2022/ThaiTranslator/actions/workflows/release.yml/badge.svg)](https://github.com/tiger-git2022/ThaiTranslator/actions/workflows/release.yml)
![平台](https://img.shields.io/badge/%E5%B9%B3%E5%8F%B0-Windows%20%7C%20macOS-blue)

把泰语会议内容实时翻译成中文：窗口里显示双语记录，屏幕上叠加一个置顶字幕浮窗，还可以共享给同一局域网里的手机和电脑。翻译和语音识别都调用运行模型的电脑（tiger-pc）上的 llama-swap，其他电脑通过 Tailscale 远程使用。

字幕有两种来源，在“字幕”页右上角切换：

```
Teams 字幕：Teams 桌面版字幕 ──UI Automation 直接读取──┐
           Teams 网页版字幕 ──浏览器扩展──────────────┴► 本软件 ──► hymt2 翻译 ──► 窗口 / 浮窗 / 局域网共享
语音识别：  电脑放出的声音 ──录音、断句──► whisper-th 识别 ──► hymt2 翻译 ──► 同上
```

### Mac 版

支持 macOS 14（Sonoma）及以上。Mac 版目前只能读取 **Teams 网页版**的字幕：用 Chrome 或 Edge 打开 teams.microsoft.com 开会，第一次用时点“安装扩展”装好浏览器扩展。翻译、置顶浮窗、局域网共享、观看共享都和 Windows 版一样。Teams 桌面版字幕和语音识别暂时只有 Windows 版支持。

软件没有苹果开发者签名，第一次打开要多点一步：

1. 解压后把 `泰语字幕翻译.app` 拖进“应用程序”文件夹，双击打开，看到“无法验证开发者”的提示时点“完成”。
2. 打开“系统设置 → 隐私与安全性”，拉到最下面，点“仍要打开”，再输一次开机密码。之后就能正常双击打开了。
3. 如果提示“已损坏，无法打开”，打开“终端”，粘贴下面这行并回车，再双击打开：

   ```
   xattr -dr com.apple.quarantine /Applications/泰语字幕翻译.app
   ```

第一次开始共享时，macOS 会问是否允许访问本地网络，要点“允许”。配置、记录和日志在 `~/Library/Application Support/ThaiCaption`。

## 在新电脑上使用（负责抓字幕和翻译的“主机”）

1. **连上翻译服务**：安装 Tailscale 并加入同一网络（或者由 tiger-pc 把节点共享给这台电脑）。
2. **运行软件**：把整个 `泰语字幕翻译` 文件夹拷过去，双击 `泰语字幕翻译.exe`。在“设置 → 翻译服务”里填好接口地址 `http://<tiger-pc 的 Tailscale 地址>:8080/v1`（在 Tailscale 管理页或 tiger-pc 上运行 `tailscale ip -4` 查看） 和 API 密钥，再点“测试翻译”。
   - 不方便连 tiger-pc 时，可以把“翻译走哪里”改成 **线上 API**，填线上服务的接口地址（OpenAI 兼容，一般以 `/v1` 结尾）、密钥和模型名，再点“测试翻译”。线上出错时字幕页会红字提示并弹窗，随时可以切回本地模型。语音识别仍然用 tiger-pc。
   - 线上 API 的“思考模式”默认**关闭**（DeepSeek 约 1 秒一句，适合实时字幕）；选 **low** 译文更细（财务术语更准、漏译更少），但每句要多等几秒。只影响定稿，临时译文总是关闭思考。线上服务不认思考字段时，软件会自动去掉字段重试。
3. **选字幕来源**（二选一）：
   - **Teams 字幕**：用 **Teams 桌面版**开会的话什么都不用装，软件会自动读取会议窗口里的实时字幕（Teams 最小化或被挡住也行）；用浏览器开会的话需要装浏览器扩展（见下一节）。会议里依次点“更多” → “语言和语音” → “显示实时字幕”，再把**会议口语语言设为泰语**。有说话人姓名。两边都开着字幕时，软件只用先出字幕的那一边，同一句不会翻译两次；Teams 把同一个人的名字一会儿显示成“Tiger Wang”、一会儿显示成“Wang Tiger”，软件会当成同一个人。
   - **语音识别**：不需要扩展，Teams 桌面版、网页版、Zoom、视频都能用。软件直接录电脑放出来的声音（在“设置 → 语音识别”里选声音从哪个耳机或音箱放出），交给 tiger-pc 上的泰语识别模型。没有说话人姓名。

## 安装浏览器扩展（只有用浏览器开 Teams 会议才需要，每台电脑一次）

点“字幕”页上的“安装扩展”，按向导操作（支持 Chrome 和 Edge）：

- 点“打开浏览器并复制地址”，在地址栏按 Ctrl+V 再回车，进入扩展管理页。
- 打开“开发者模式”。
- 点“复制扩展路径”，再点浏览器里的“加载已解压的扩展程序”，粘贴路径并选择文件夹。也可以直接把文件夹拖进扩展管理页。
- 向导显示“已安装”就完成了。之后浏览器工具栏上的扩展图标显示 **ON** 表示已连上软件，显示 **!** 表示软件没开。

浏览器不允许程序自动安装扩展，也不允许程序直接打开 `chrome://` 页面，所以这几步要手动点一下。

## 共享字幕（局域网）

只有主机需要 Tailscale 和翻译服务；手机和其他电脑只要连**同一个 Wi-Fi / 局域网**，什么都不用装：

- **开始共享**：主机点“共享字幕”，会弹出二维码、地址（例如 `http://192.168.3.155:47322/`）和 6 位观看码。点“停止共享”随时取消。
- **手机看**：扫二维码，用浏览器打开就能看。可以调字号、隐藏原文，跟随手机的深浅色。主机停止共享后网页会提示，主机重新共享时会自动接上。观看码存在手机浏览器里，下次直接打开地址就行。
- **其他电脑看**：可以同样用浏览器扫码或打开地址；装了本软件的话，点“观看共享”会自动在局域网里找到主机，或者先复制主机的共享链接再点“观看共享”（会自动填好），字幕会显示在主窗口和置顶浮窗里。
- **连不上时**：确认在同一个 Wi-Fi（访客网络通常禁止设备互访）。主机第一次共享时，Windows 防火墙弹窗要点“允许”。
- 共享名称、共享端口可以在设置里改；“重置观看码”后，之前扫过码的手机要重新扫码。

## 功能

- **边说边翻**：说话过程中先显示灰色的临时译文，说完一句后换成定稿译文。
- **参考上文**：把前两句原文一起发给模型，代词和省略翻得更准。
- **术语表**：每行写一条“泰文=译文”，原文里出现这个词时才会发给模型。软件内置了几条泰文拼写的英文词（ดูพลิเคท=复制、ดีไซน์=设计、โปรเซส=流程、เซฟ=保存、สเต็ป=步骤），自己的术语表里写了同一个词时以自己的为准。
- **泰英混说**：泰语里夹英文词、整句英语都能翻；线上 API 会把 review、finance 这类普通英文词也译成中文，只保留 UAT、SAP 这类缩写。
- **译文不留泰文**：泰语人名、昵称音译成汉字，泰文字母写成拉丁转写（กอไก่ → 字母 ko kai）。定稿译文里还有泰文时会自动重翻一次。个别人名音译不理想时，在术语表里写一条“泰文名=中文名”。
- **识别乱码**：会议口语语言设为泰语时，Teams 会把英语发言识别成乱码。线上 API 会按读音尽量还原成英文再翻，不写“（听不清）”。用本地 hymt2 时，软件会先检查英文部分是不是乱码（不认识的词占比高），是的话整句改送线上 API（填了的话）。日志里会记下每条判定为乱码的句子。如果某段会议主要说英语，可以在 Teams 里临时把口语语言切成英语。
- **复制字幕**：主窗口的字幕区可以像网页一样用鼠标连续拖选多条，Ctrl+A 全选，Ctrl+C 复制，复制出来带时间和说话人；右键还能单独复制某一条的译文或原文。文字按窗口宽度自动换行，泰文按词换行。
- **浮窗**：在空白处（边缘、行尾）按住可以拖动，拖右下角改大小，Ctrl+滚轮调字号。在文字上按住拖动是选中文字，选中期间浮窗暂停刷新，按 Ctrl+C 或右键复制，按 Esc 或单击空白处继续；右键也可以一次复制浮窗上的几条字幕（带时间和说话人）。直接滚动鼠标滚轮可以往上翻看历史字幕（翻看时新字幕不会把画面顶走），向下滚到底或双击浮窗回到最新。右键菜单里有显示原文、毛玻璃、鼠标穿透等选项。开启鼠标穿透后，要从托盘图标的菜单里取消。
- **记录**：每 15 秒自动保存到 `%APPDATA%\ThaiCaption\transcripts`，也可以从“记录”菜单导出为 Markdown。
- **日志**：写在 `%APPDATA%\ThaiCaption\logs\`，每天一个文件，保留 7 天。会记录启动信息、Teams / 扩展状态变化、每句的识别和翻译结果及耗时、模型状态、共享连接，以及所有报错和崩溃堆栈。“记录”菜单和设置页都能打开日志文件夹；设置里的“详细日志”会额外记录每次临时识别和临时翻译。出问题时，把当天的日志发出来就能排查。
- **外观**：可选云母、亚克力、云母 Alt 或纯色背景，亚克力遮罩可调，支持深色和浅色主题。

## 服务端（tiger-pc 上的 llama-swap）

- `hymt2`（Hy-MT2-7B）：翻译，推荐。每句约 0.2–0.7 秒。`hymt2-32k` 是同一个模型，上下文更长。
- `whisper-th`：泰语语音识别。模型是 biodatlab/distill-whisper-th-large-v3（Thonburian Whisper 蒸馏版，Common Voice 词错率 6.82%），转成 whisper.cpp 格式并量化为 q8_0，约 1.6 GB 显存，每句识别约 0.1–0.2 秒。程序和模型在 `E:\whisper.cpp`。
- **模型会自动加载，不用手动点**：软件切到“语音识别”，或检测到 Teams 字幕已开启时，会立刻让 llama-swap 加载需要的模型（识别模型约 3 秒、翻译模型约 8 秒）。使用期间每 4 分钟轻轻请求一次，防止空闲 5 分钟被卸载；不用了（关掉软件、Teams 字幕关闭超过 10 分钟、只是在看别人共享）就不再保持，模型按时自动卸载，释放显存。状态栏会显示“模型已就绪 / 加载中 / 未加载”。前提是 tiger-pc 上的 llama-swap 已经启动（控制面板开机自启）。
- `hymt2` 和 `whisper-th` 在同一个分组里，可以同时加载（两个加起来约占 11 GB 显存）；切到 `qwen36` 等其他模型时会一起换下。
- 也支持其他 OpenAI 兼容的翻译模型，会自动改用通用的同传提示词。

## 开发

```
pip install -r requirements.txt   # 安装依赖（PySide6、qfluentwidgets、pyaudiowpatch、onnxruntime 等）
python app\main.py         # 直接运行
python build.py            # 打包到 dist\泰语字幕翻译\（在 Mac 上运行则打包成 dist/泰语字幕翻译.app）
python build.py --onefile  # 单文件版 dist\泰语字幕翻译-版本号-单文件.exe
```

环境变量 `THAICAPTION_HOME` 可以指定另外的配置目录，方便测试。扩展的端口写在 `extension\background.js` 的 `PORT` 里，要和软件设置里的“本机端口”一致。模型转换脚本在 `E:\whisper.cpp\tools\convert_safetensors.py`（不需要 PyTorch）。

Teams 桌面版字幕的读取在 `app\teams_desktop.py`：找 `ms-teams.exe` / `Teams.exe` 的窗口，读名为“实时字幕”的区域，按“说话人、文本”配对，按内容和上一次读到的字幕对上号（界面元素的标识不可靠）。测试时可以设环境变量 `THAICAPTION_TEAMS_EXE=msedge.exe`，用浏览器打开一个结构类似的网页代替 Teams。

### 发布新版本

1. 改 `app\main.py` 里的 `APP_VERSION`，在 `CHANGELOG.md` 顶部加一节 `## v新版本号`，写这次改了什么。
2. 合并（或推送）到 `main`。GitHub Actions 发现这个版本号还没有 `v版本号` 标签，就会在 Windows 和 Mac 上分别打包、做启动自检，自动发布到 Releases 并打上标签，说明取自 `CHANGELOG.md`。版本号没变时推到 `main` 什么都不做。
3. 也可以自己推标签 `v新版本号` 来发布；标签和 `APP_VERSION` 不一致时会直接报错，不发布。

只想试打包、不发布时，在 Actions 页面手动运行“打包发布”，产物在那次运行的 Artifacts 里下载。
